# jhste-llm-bench

Personal benchmark of LLM workers on the [omp](https://github.com/can1357/oh-my-pi) harness with subscription models.

- Leaderboard: https://jhste102lab.github.io/jhste-llm-bench/ (static site in `docs/`)
- Method: [`PROTOCOL.md`](PROTOCOL.md) and `protocol/v2.json`

## Layout

| Path | Contents |
|---|---|
| `docs/` | GitHub Pages site. `data/bench.js` = v1 results, `data/v2.js` = generated by `bench export` |
| `bench/` | runner, grading and export (`python3 -m bench`, stdlib only, macOS) |
| `protocol/` | pinned protocol and hashed leak terms for CI |
| `tests/` | offline unit tests with synthetic fixtures |

Task material, oracles, raw sessions and grades live in a private local bench home (`BENCH_HOME`, default `~/.omp/experiments/jhste-llm-bench`) and are never committed.

## Adding a model

```sh
python3 -m bench lock                      # once after pack or protocol changes
python3 -m bench run --role task --model <provider/model> --effort <effort>
python3 -m bench run --role scout --model <provider/model> --effort <effort> [--judge <model>:<effort>]
python3 -m bench status
python3 -m bench export                    # writes docs/data/v2.js after the leak gate
```

The role baseline is rerun in every batch. Quota stops or harness faults are retried with `python3 -m bench run --retry <batch>`; a quarantined batch (baseline drift) is published only after `python3 -m bench accept <batch>`.

Other commands: `pack snapshot`, `freeze`, `isolation-check`, `grade`, `leak-hashes` (see `python3 -m bench <command> --help`).
